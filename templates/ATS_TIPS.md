# ATS Tips

Tips and tricks for specific Applicant Tracking Systems. The job-applicator
agent adds new learnings here as it encounters them.

## General (All Platforms)
- Always upload PDF versions of resume and cover letter, never .docx
- Never let the site parse the resume automatically, always fill in manually
- When extracting work history from a .docx resume, clean up the text: remove
  extra spaces from line wrapping, convert ALL CAPS titles to Title Case, format
  descriptions as bullet points (one per line, using U+2022) not paragraphs
- Never use em-dashes in text fields. Avoid parentheses unless necessary.
- Some companies ask about AI tool usage. Keep a pre-written answer ready.

## Workday
- Forms have these steps: My Information, My Experience, Application Questions,
  Voluntary Disclosures, Self Identify, Review. Required fields marked with *.
- Upload the PDF resume first. When offered to auto-parse, choose "Fill in manually."
- Search/autocomplete fields (School, Field of Study): type the value, press Enter,
  wait 1 second, check if it auto-selected. Only click dropdown if auto-select failed.
- Dropdowns: click the dropdown button to open, read options, click to select.
  Sometimes a hidden textbox appears that you need to type in.
- Date fields use spinbutton inputs with separate Month and Year. Set month as
  number ("5" or "05"), year as 4 digits ("2024").
- "I currently work here" checkbox hides the "To" date fields when checked.
- Role descriptions: use bullet character (U+2022), each on its own line.
- LinkedIn profile field uses full URL format: https://www.linkedin.com/in/yourslug
- Field of Study autocomplete varies by instance. Always check available options by
  typing and reviewing dropdown suggestions before committing.
- Submit button on Review page takes a few seconds to process. Confirmation URL
  contains "applythankyou?status=success" indicating successful submission.

## Greenhouse
- Single-page application form with no pagination. All fields (personal info,
  custom questions, EEO/demographics, file uploads) on one long page.
- Submit button at bottom labeled "Submit application."
- After submission, redirects to /confirmation with "Thank you for applying" title.
- Fields use combobox dropdowns with autocomplete for location, gender, race,
  veteran status, and disability status.
- For Location (City) field: type city name, wait for autocomplete suggestions,
  select matching option. Displays as "City, State, Country" format.
- File upload shows filename with "Remove file" button after uploading.
- Phone field has a separate country code selector.
- reCAPTCHA is present but does not require manual solving in normal flow.
- Clear selections button available if you need to change a selection.
