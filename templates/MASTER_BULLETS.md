# Master Bullets

All unique accomplishment bullets across all resume variants, organized by company. This is the single source of truth for available content.

## How to Use
- The resume-optimizer agent reads this file first when starting any optimization
- Match job requirements to bullets from this master list
- Select the best-fit bullets for each company section
- Tailor wording as needed while preserving the core accomplishment
- Never fabricate accomplishments -- all bullets must be based on real achievements
